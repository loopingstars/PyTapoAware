# PyTapoAware
PyTapoAware é um sistema inteligente de automação em Python para lâmpadas Tapo. Ele responde a eventos de presença (via webhook) e acende automaticamente a luz, com lógica configurável baseada em horário e estado atual da lâmpada.  Ideal para integração com ICSee, Automate, Tasker, Node-RED e outros sistemas que enviam notificações HTTP.
